# Block Atlas | Neighborhood Resource Map

Block Atlas is a neighborhood directory map for exploring nearby food access, health support, learning spaces, and community services.

The app is being built with React, Vite, and local sample listings. Example locations are provided for demonstration and should be checked before anyone relies on them for real-world services.

## Run locally

Install dependencies with npm install, then start the development server with npm run dev.

Run npm run lint and npm run build to check the project.
